# Dokümantasyon Standardı

İyi belge, yazarı yanında olmadan kullanılabilir.

## Belge türleri

| Tür | Cevapladığı soru |
| --- | --- |
| Rehber | Bir hedefe nasıl ulaşırım? |
| Referans | Alan, komut veya API tam olarak nedir? |
| Runbook | Operasyon veya arıza anında ne yaparım? |
| ADR | Bu teknik kararı neden aldık? |
| Açıklama | Sistem nasıl ve neden böyle çalışıyor? |

## Yazım ilkeleri

- Başta amaç ve hedef kitleyi belirtin.
- Uygulanabilir adımları sıralı ve doğrulanabilir yazın.
- Parola, token, kişi adı ve geçici erişim ayrıntısı eklemeyin.
- Ekran görüntüsü yerine mümkünse aranabilir metin kullanın.
- Zamanla değişen bilgiye sahip ve gözden geçirme tarihi ekleyin.
- Dosya ve bağlantıları göreli kullanarak yerel önizlemeyi koruyun.

## Güncellik

Belgeyi etkileyen değişiklik aynı pull request içinde belgeyi de günceller. Artık geçerli olmayan belge sessizce bırakılmaz; güncellenir, arşivlenir veya kaldırılır.
