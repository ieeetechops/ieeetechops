# TechOps Yol Haritası

Bu yol haritası yön gösterir; güncel görevler GitHub Issues ve Projects üzerinden takip edilir.

## Şimdi — Temel yapı

- [x] TechOps dokümantasyon deposu
- [x] Katkı, güvenlik ve yönetişim kuralları
- [x] Issue ve pull request şablonları
- [x] GitHub Pages dokümantasyon altyapısı
- [ ] Proje ve servis sahiplerinin doğrulanması
- [ ] Kurumsal hesap ve erişim envanteri
- [ ] GitHub organizasyonu takım/yetki düzeni

## Sırada — Standartlaştırma

- [ ] Yeni proje başlangıç şablonu
- [ ] Servis envanteri ve sorumluluk matrisi
- [ ] Erişim gözden geçirme süreci
- [ ] Drive klasör ve paylaşım standardı
- [ ] Yedekleme ve kurtarma testleri
- [ ] Teknik karar kayıtlarının tamamlanması

## Sonra — Ürünler ve entegrasyonlar

- [ ] Başvuru ve operasyon platformu
- [ ] Üyelik altyapısı iyileştirmeleri
- [ ] HeptaCert veri entegrasyonu
- [ ] Etkinlik raporlama otomasyonu
- [ ] Servis durumu ve gözlemlenebilirlik
- [ ] Yönetim dönemi devir paneli

## Uzun vadeli hedef

Her kritik servisin kurumsal sahibi, yedeği, erişim modeli, güncel runbook'u ve test edilmiş kurtarma yöntemi bulunmalıdır. Yeni yönetim, sistemi yeniden kurmak yerine mevcut yapının üzerine geliştirme yapabilmelidir.

## Yol haritasına katkı

Yeni bir öneri için **Yeni proje önerisi** issue formunu kullanın. Öncelik; etki, aciliyet, bakım maliyeti, güvenlik ve ekip kapasitesi birlikte değerlendirilerek belirlenir.
